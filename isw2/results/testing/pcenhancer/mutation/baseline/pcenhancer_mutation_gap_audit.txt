Metric definitions
------------------
Mutation Score =
    KILLED / TOTAL MUTANTS

Test Strength =
    KILLED / (KILLED + SURVIVED)

NO_COVERAGE mutants are reported separately.
They are not automatically interpreted as oracle weaknesses.

Formal interpretation rule
--------------------------
SURVIVED mutants:
    production code was reached by at least one test, but the current
    observable oracle did not distinguish the mutant.

NO_COVERAGE mutants:
    mutated code was not exercised by the PIT execution subset.
    They are retained as reachability evidence but are not automatically
    selected for T_MT.

No survivor is automatically classified as equivalent.
No mutation-guided test is selected by this audit alone.

Candidate ranking is descriptive, not prescriptive:
    1. number of surviving mutants;
    2. survivor rate among covered mutants;
    3. diversity of surviving mutator types.
