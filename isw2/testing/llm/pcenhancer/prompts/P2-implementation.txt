# P2 - Implementation

Continua lo stesso esperimento su:

org.apache.openjpa.enhance.PCEnhancer
Apache OpenJPA 4.1.1

Implementa in JUnit Jupiter esattamente i 30 test case/scenari
TLLM-001 ... TLLM-030 definiti nella risposta al Prompt P1.

Ambiente:
- Java 21
- JUnit Jupiter
- Mockito disponibile ma non obbligatorio

Usa esclusivamente:
- il production context fornito nella run corrente;
- i 30 test case/scenari definiti nella risposta P1.

Non utilizzare:
- test nativi OpenJPA;
- altre suite sperimentali;
- risultati JaCoCo;
- risultati PIT;
- survivor mutation;
- Web o fonti esterne.

Vincoli:
- non aggiungere test case rispetto a P1;
- non eliminare test case rispetto a P1;
- non sostituire test case rispetto a P1;
- non modificare il production code;
- non inventare API o comportamenti mancanti.

`N = 30` indica i 30 test case/scenari definiti in P1, non un vincolo sul
numero di metodi Java `@Test`.

L'organizzazione del codice è libera. Puoi utilizzare:
- una o più classi di test;
- fixture;
- setup condiviso;
- helper;
- utility di test.

Tali elementi di supporto non costituiscono test case aggiuntivi.

Output richiesto:
1. codice Java completo della suite;
2. eventuali fixture/helper necessari;
3. mapping `TLLM-001 ... TLLM-030` -> implementazione corrispondente;
4. conferma che tutti e soli i 30 test case definiti in P1 sono rappresentati.

Se uno o più casi non sono implementabili con il production context
disponibile, non sostituirli con casi diversi e non inventare API: indica
soltanto il blocco tecnico e i file production realmente necessari.
